# Φάση 0 και κίνδυνοι

## Μια σκόπιμα περιορισμένη απόφαση

1. έως 18 μήνες,
2. ανώτατο όριο χρηματοδότησης 1,6 εκατ. ευρώ,
3. μόνο γνωμοδοτήσεις, προσομοιώσεις, testnet χωρίς πραγματική αξία και εργαστηριακή εργασία,
4. ενδιάμεση απόφαση μετά από εννέα μήνες,
5. αυτόματος τερματισμός χωρίς νέα απόφαση συνέχισης.

Το εύρος 0,95–1,65 εκατ. ευρώ είναι **πρόταση και όχι εγκεκριμένη χρηματοδότηση**. Δεν περιλαμβάνει production infrastructure, έκδοση χαρτονομισμάτων με αξία ή mainnet liquidity.

## Χρονοδιάγραμμα

| Μήνας | Απαιτούμενη απόδειξη |
|---|---|
| 0–3 | νομικά ερωτήματα, invariants, μοντέλα συστήματος, περιβάλλον testnet |
| 4–6 | Constitution/Bearer proof of concept και supply indexer |
| 7–9 | CashLot, offline εργαστήριο και ενδιάμεση απόφαση |
| 10–12 | attack simulation, migration και exit test |
| 13–15 | ολοκληρωμένο demo χωρίς πραγματική αξία και ανεξάρτητο red team |
| 16–18 | τελική γνωμοδότηση: Go, No-Go ή Research-Only |

## Υποχρεωτικά κριτήρια διακοπής

- η νομική ανάλυση δεν βρίσκει ασφαλή ερευνητική ή πιλοτική διαδρομή,
- το `S ≤ Mmax` ή η απουσία διπλού υπολογισμού δεν αποδεικνύεται ανεξάρτητα,
- compiler, wallet ή indexer δεν είναι επαρκώς ώριμα,
- CashLot fraud ή offline double spend υπερβαίνει το εγκεκριμένο όριο ζημίας,
- το Genesis sunset ή key burn μπορεί να παραταθεί ή να παρακαμφθεί,
- η εξάρτηση από Kaspa δεν έχει αξιόπιστη διαδρομή migration,
- privacy, AML ή έλεγχος φυσικών σειρών δημιουργούν απαράδεκτο κίνδυνο,
- το έργο παρουσιάζεται πολιτικά ως ήδη αποφασισμένο παράλληλο νόμισμα.

## Συνοπτικό μητρώο κινδύνων

| Κίνδυνος | Πρώιμο σήμα | Αντιμετώπιση | Υπολειπόμενος κίνδυνος |
|---|---|---|---|
| covenant/compiler error | διαφορετική εκτέλεση, audit finding | formal specification, δύο ανεξάρτητα audits | άγνωστο logic flaw |
| Kaspa reorg ή fees | βαθύ reorg, συγκέντρωση, fee stress | finality window, fee policy, migration test | εξωτερικό δίκτυο |
| CashLot fraud | απόκλιση μητρώου/lock | inventory, bonds, serial commitments | φυσική συμπαιγνία |
| παραχάραξη | αυξανόμενες απορρίψεις | χαρακτηριστικά ασφαλείας, machine checks | κοινωνική ζημία |
| offline double spend | ανωμαλίες counters | όρια ποσού, χρόνου και hops | περιορισμένη ζημία εμπόρου |
| governance capture | συγκέντρωση, βιαστικές προτάσεις | sunset, timelocks, immutable core | επιρροή στα άκρα |
| κρατική πίεση | προτάσεις κατάσχεσης ή απαγόρευσης | self-custody, καταστροφή keys, ένδικα μέσα | η χρήση ρυθμίζεται |
| τραπεζική/ρευστότητα | εκροές, mismatch διάρκειας | 100% reserve, funds, ομαλή αφερεγγυότητα | χωρίς απεριόριστο LOLR |
| κοινωνική απόρριψη | «δεύτερη δραχμή σημαίνει κρίση» | εθελοντική δοκιμή, διαφάνεια | η εμπιστοσύνη δεν προγραμματίζεται |

## Ειλικρινής υπολειπόμενος κίνδυνος

Σταθερή προσφορά μπορεί να ενισχύσει τον αποπληθωρισμό και το πραγματικό βάρος χρέους. Το narrow banking μπορεί να ακριβύνει την πίστωση. Χαρτονομίσματα και κέρματα εξαρτώνται από ανθρώπινους θεσμούς. Η offline οριστικότητα είναι περιορισμένη. Το Kaspa δεν αντικαθιστά το εθνικό δίκαιο ή στρατηγική migration. Η τεχνολογία δεν καθιστά αδύνατη την απαγόρευση, τον αποκλεισμό από αγορές ή τη γεωπολιτική απόρριψη.

Η Φάση 0 είναι υπεύθυνη ακριβώς επειδή το **No-Go** αποτελεί αποδεκτό και χρήσιμο αποτέλεσμα.
